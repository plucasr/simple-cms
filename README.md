# Simple CMS

Custom CMS I wrote in 2014-2015 while experimenting with PHP and databases on my own.

Plain PHP 5, MySQL, Bootstrap 3 and jQuery. No frameworks, no composer — just figuring out how
a dynamic site fits together: pages that pull from a database, a small admin area, login
with sessions, forms that write back to MySQL.

I keep it public as a snapshot of that experiment.

Warning: this is old code. md5 passwords and concatenated SQL were normal for self-taught
experiments back then, but please don't copy those parts.
